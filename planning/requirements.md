# 暇つぶしゴルフゲーム 要件定義（v0.1）

`ideas.md` でのアイデア出しを踏まえた、初期スコープの要件まとめ。
細部は試作しながら随時更新していく（決定事項として固めすぎない）。

## 1. コンセプト

| 項目 | 内容 |
|---|---|
| ターゲット | 10代〜20代、暇つぶしで遊ぶカジュアル層 |
| プラットフォーム | スマホ（iPhoneでリリース・プレイ可能なこと必須） |
| 画面向き | 縦型（ポートレート） |
| セッション時間 | 最短1分程度〜、やり込めば5〜10分 |
| 開発方針 | 「AI駆動」= 開発プロセスをAIで進める（ゲーム内にAI要素は入れない） |
| ジャンル | ハイパーカジュアル。題材はゴルフ、カード選択による育成ローグライト要素あり |

## 2. コアゲームループ

1. プレイ開始 → 1プレイ = 3ホール（Par5 → Par4 → Par3、初期スコープ）
2. 各ホールでショットを行う（パワー・方向を決めて打つ）
3. ショットの節目・ホール間などで育成カードが提示される（詳細タイミングは試作で調整）
4. カードから1枚選択し、キャラクターを成長させる、またはクラブを入手する
5. 3ホール終了 → 合計スコア（対Par）を表示してリザルト

## 3. 育成・カードシステム

- **成長ステータス**: コントロール / パワー / テクニックの3方向。プレイヤーが伸ばす方向を選択できる
- **カード選択**: 複数の選択肢（カード）から1つを選ぶ。選択肢の内容は毎回ランダムに提示される
  - 例: 「ステータス強化カード（将来性重視）」と「クラブ入手カード（即効性・運要素）」がトレードオフで並ぶ
- **クラブ**: 運要素。ランダム提示されたクラブを取得することで飛距離やショット性能が変化する
- **数値インフレ演出**: 成長に応じてスコアが目に見えて変化する（序盤はダブルボギー相応 → 育成が進むとPar5でアルバトロスも狙えるレベルまで化ける）
- **運要素の強さ**: 過度な運ゲー化は避ける方針。強さの最終調整は試作プレイを通じて決定

## 4. ショット操作仕様

- なるべく簡易な操作にする（リズムゲーム風のタイミング入力）
- 「パワー」「方向」をそれぞれ11段階（0〜10、中央値が存在する奇数段階）で決定
- 画面上をバー（ゲージ）に沿って的（カーソル）が動き、任意のタイミングでタップして位置を確定
  - 1回目のタップ: パワー確定
  - 2回目のタップ: 方向確定

## 5. ホール仕様（初期スコープ）

| ホール | Par | 距離 | 備考 |
|---|---|---|---|
| 1 | 5 | 530ヤード | まっすぐな形状（ドッグレッグなし） |
| 2 | 4 | 340ヤード | まっすぐな形状（ドッグレッグなし） |
| 3 | 3 | 160ヤード | まっすぐな形状（ドッグレッグなし） |

- グリーン周りにガードバンカーを2個程度配置
- コース形状の細部（起伏・池・OBなど）は試作を通じて後から詰める

## 6. 将来的な拡張（初期スコープ外）

- プレイモードの追加: 1ホールのみプレイ / 9ホール（ハーフラウンド）/ 18ホール（1ラウンド）
- コース形状のバリエーション（ドッグレッグ、池、OBなど）
- 収益化（広告・課金）の設計
- キャラクター/クラブの見た目バリエーション

## 7. 未決事項（要検討）

- カード提示・選択が発生する具体的なタイミング（ショットごと？ホールごと？）
- クラブとステータスのバランス調整の詳細
- リザルト画面の演出・共有機能の有無
- タイトル名
