# 暇つぶしゲーム 企画メモ

AI駆動で作る、暇つぶし用ゲームのアイデア出し段階のメモ。
ここでアイデアを広げて、固まったら `requirements.md` に要件として落とし込む。

## コンセプト（決定事項）

- **ターゲット**: 10代〜20代、暇つぶしで遊ぶカジュアル層
- **プラットフォーム**: スマホ（iPhoneでリリース・プレイ可能なこと必須）
- **画面デザイン**: 縦型（ポートレート）
- **セッション時間**: 最短1分程度で遊べる。やり込めば5〜10分続けられる設計
- **「AI駆動」の意味**: ゲーム内にAI要素を入れるのではなく、**開発プロセスをAIで進める**という意味
- **ジャンル**: ハイパーカジュアル（Hyper Casual）。広告でよく見る「左右スワイプで味方の数を増やしながら相手を倒していく」タイプのゲームをイメージ

## 面白さの核となるコアメカニクス

- **カード選択によるカスタマイズ**: いくつかのカード選択肢から1つを選んでいく。「何を選ぶか」を自分の意思決定に委ねるのが面白さの中心
- **選択の分岐 → 状況/ゴールの変化**: 選んだ結果によって自分の状況やたどり着くゴールが変わる（一本道ではない）
- **数値インフレを楽しむ**: ステータスが爆上がりしていく快感（いわゆる「クソゲー」に共通する、脳が気持ちいいと感じるやつ）を意図的に取り入れる
- **意思決定に応じたキャラ成長**: 選んだ方向にキャラクターが成長していく（どの道を選んでも成長はするが、伸びる方向が変わる）
- **ストレスにならない程度の運要素**: 選択肢の出現がランダム（乱数）。毎回同じ選択肢が出るわけではないため再現性が低く、試行回数を重ねないと理論値（最適解）が見えてこない設計にしたい

### 2. ゴルフ×カード選択・育成ローグライト（本命案）
- どんなゲーム: ゴルフを題材にした、カード選択で主人公を育成していくハイパーカジュアル寄りのゲーム。自分の趣味（ゴルフ）を題材に絡める
- 遊び方（現時点のイメージ）:
  - 主人公キャラクターがおり、ラウンド/ショットの節目で提示されるカード（選択肢）から1つを選んで成長・強化していく
  - 成長ステータスは「コントロール」「パワー」「テクニック」の3方向があり、どの方向に伸ばすかをプレイヤーが選択できる
  - 運要素として「クラブ」がある。クラブは運（ランダム提示）で取得できるかどうかが決まる
  - 選択肢には「クラブ強化（飛距離アップなど即効性）」と「ステータス強化（コントロール/パワー/テクニック、将来性重視）」が並行して出てくる
    - 例: 「今すぐ飛距離を伸ばすクラブを取るか」「後々のために地道にステータスを上げておくか」というトレードオフの意思決定が発生
  - 成長度合いによってスコアの結果が変化する: 序盤〜下手なうちはダブルボギーなども当たり前、うまく育成が進むとPar5でアルバトロスが出せるくらいまで化ける、という成長の実感を演出
- 面白いと思うポイント:
  - ゴルフというテーマとの相性（クラブ選び・飛距離・スコアという概念が自然にカード育成システムと結びつく）
  - 「クラブを取るか、ステータスを取るか」のようなトレードオフの意思決定が毎回発生し、リプレイ性が出る
  - スコアの伸び（ダブルボギー→アルバトロス）が数値インフレ・成長実感としてわかりやすい
- **1プレイの構成（ホール数）**:
  - まずは「Par5・Par4・Par3を1つずつ、計3ホール」のプレイに絞って作る（初期スコープ）
  - 将来的には1ホールのみのプレイ、9ホール（ハーフラウンド）、18ホール（1ラウンド）など複数モードを用意したい（後回しでOK）
- 気になる点/懸念 → 現時点の回答:
  - **テンポ感**: ホール間はさくさく進められるようにしたい。最初から作り込みすぎず、一旦プロトタイプを作ってプレイしながら調整案を出していく方針
  - **運要素の強さ**: 基本的にはそこまで強く出したくない（運ゲー感を抑えたい）。ただし最終的な強さ・バランスは実際にプレイして決める
  - **ショット操作**: なるべく簡易な操作にしたい。案は以下の通り
    - 画面にバーを表示し、「パワー」と「方向」をそれぞれ決める
    - パワー・方向ともに11段階（奇数にして中央値を作る。例: パワーは弱⇔強、方向は右⇔左で、それぞれ0〜10の11段階）
    - バー上を的（カーソル）が動いてきて、任意のタイミングでタップして止める → その位置でパワー/方向が確定
    - リズムゲームのようなタイミング入力にする（パワーと方向で2回タップする想定）
- **ホール設計（初期スコープ・ラフ案）**:
  - コース形状: 細かい設計はまだ詰めない。ドッグレッグ（右/左）などは考えず、まずはまっすぐなホールのみ
  - バンカー: グリーン周りにガードバンカーを2個程度配置
  - 距離設定: Par5 = 530ヤード / Par4 = 340ヤード / Par3 = 160ヤード
  - 補足: 実際に試作・プレイしてみないと判断できない部分が多いため、細部は後回しでOKという方針
