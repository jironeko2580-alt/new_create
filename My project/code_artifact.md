# 2D物理マージパズル 要件定義書 (v1.1)

## 1. プロジェクト概要
- **プロジェクト名:** 2D物理マージパズル（MVP版）
- **制作エンジン:** Unity (Universal 2D / URP)
- **ターゲットプラットフォーム:** WebGL (unityroom 公開想定)
- **想定プレイ時間:** 1プレイ 2〜3分
- **操作方式:** マウス操作（左右移動で狙いを定め、左クリックで投下）

---

## 2. 目的・ゴール
- **第一目標:** 企画からUnityでの実装、WebGLビルド、unityroom公開までを一気通貫で完走する。
- **制作方針:** 実用最小限の機能（MVP: Minimum Viable Product）に絞り、複雑なギミックは実装しない。

---

## 3. ゲームルール・サイクル
1. **投下フェーズ:**
   - 画面上部に次回投下されるボールが追従表示される（マウスのX座標に同期）。
   - クリックしたタイミングでボールの物理挙動が有効化され、重力によって箱内へ落下する。
   - 投下後、次のボールが表示されるまで **0.5秒** のクールダウンを設ける。
   - ボールの位置は、ボールの半径を考慮して箱の内側に収まるよう左右を制限する。
2. **物理・マージフェーズ:**
   - ボールは箱の壁や他のボールと物理演算（Rigidbody2D / CircleCollider2D）によって反発・転がりを行う。
   - **同じレベルのボール同士が衝突**した際、片方の位置（**2つのうち下にある方**）に1段階上位のボールが生成され、双方が消滅する。
   - マージ発生時に、**生成されたボールのレベルの獲得スコア**が加算される（例: Lv.1同士の合体 → Lv.2の20点）。
   - ボールの質量は大きさに比例する（大きいボールほど重い）。
3. **ゲームオーバーフェーズ:**
   - 箱上部に設定された「デッドライン」をボールが **2.5秒** 超過した場合に判定。
   - 超過中のボールがある間は、デッドラインを点滅させて警告する。
   - ゲームオーバー時は物理演算を停止し、それ以上の投下を受け付けない。
   - ゲームオーバーUIを表示し、リトライボタンでシーンを再読み込みする。

## 4. ボール仕様一覧

| レベル | 名称 / カラー想定 | オブジェクトスケール | 獲得スコア | 備考 |
| :--- | :--- | :--- | :--- | :--- |

## 5. 画面構成およびUI要件

### 5.1 ゲーム画面
- **盤面（箱）:** 
  - 左右の壁（BoxCollider2D）
  - 底面の床（BoxCollider2D）
- **デッドライン（上部）:**
  - 警告用のライン表示
  - 超過検知用トリガー（BoxCollider2D: `IsTrigger = true`）
- **UI表示:**
  - 現在スコア表示（TextMeshPro: `SCORE: 0000`、画面左上）
- **画面サイズ:** unityroom標準の 960×600 を基準とする。
- **ボールの見た目:** コードで生成した円のスプライトに、レベルごとの色を付けて表示する（画像素材は後から差し替え可能）。

### 5.2 ゲームオーバー画面
- **ポップアップUI:**
  - 「GAME OVER」テキスト
  - 最終スコア表示
  - 「リトライ」ボタン（クリックで現在のシーンを再読込）
    - 標準フォントが日本語に対応していないため、ボタン表記は「RETRY」とする。
